# LearningC-

This repository documents my journey of learning C# from the basics.

My main goal is to become confident with C# and eventually use it to create my own games, especially with Unity.

I will upload exercises, small projects, experiments, and other programs as I learn new concepts.

Some of the topics I’m currently learning include:

* Variables and data types
* Loops and conditions
* Methods and return values
* Classes and objects
* Constructors
* Arrays and Lists
* Switch statements
* Object-oriented programming

As I improve, I plan to work on increasingly difficult projects and eventually move into game development.

This repository is mainly here so I can track my progress and look back at how much I’ve improved.
